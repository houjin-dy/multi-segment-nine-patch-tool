# 多段点九批量制作工具

纯前端的点九图批量制作工具，支持每张图片独立选择单段或多段点九模式。

## 本地预览

```powershell
node preview-server.mjs
```

然后访问 <http://127.0.0.1:8765/> 。

## 点九预览与横屏检查

- 支持直接导入已有的 `.9.png`，读取并去掉 1px 标记边框用于预览；再次导出时保留单层边框和原文件名，不重复添加 `.9`。
- 预览支持放大和缩小。缩小时先压缩拉伸区，低于固定区合计尺寸后压缩固定区，不能只裁切画布。布局依据 [Skia lattice 的尺寸分配规则](https://github.com/google/skia/blob/main/src/core/SkLatticeIter.cpp)，各块使用共用的整数像素边界。
- 默认显示原色，不叠加内容区辅助线。预览保持 1:1，可滚动并点击查看 100% / 200% / 400% 大图；可切换背景与平滑采样。
- “横屏模拟”使用宽 ×3、高 ×0.65 的测试尺寸，并非手机实测。若拉伸区被压没，会显示提示；可以输入实际目标像素尺寸复核。手机像素密度、渲染方式和皮肤配置仍可能影响最终效果。
- 单段模式可分别输入顶边、左边的起止像素（从 1 开始）。修改左边范围只影响纵向拉伸；原长度滑条会同时重设两个方向。对连续渐变不要仅凭居中 5px 默认值判断适用性。

## 小艺 5.0 资源命名与打包

打开 `resource-packager/index.html`，或直接双击独立的 `resource-packager.html`（完全离线，无外部依赖）。原点九工具顶部也有入口。

- 按提供的《小艺输入法5.0资源文件规范.xlsx》解析 471 条规则，前景 0～3 层展开后共 909 个资源用途。
- 上传 PNG、JPEG、点九 PNG、WebP 或 MP4。按标准文件名或简易中文名自动匹配；可将一张通用素材批量用于多个资源。
- 简名示例：`a.png`（26 键 A 背景）、`a按下.png`（按压背景）、`7.png`（9 键数字 7 背景）、`删除图标.png`、`26键空格背景.png`。`a前景第2层.png` 对应前景索引 1；省略层号的“前景”为第 1 层。保留真实文件格式，简名不是华为官方文件名，导出时会转换。
- 同名用途不自动猜测，如 `空格背景.png` 会提示选择模块；9 键换行区分 `9键普通页换行背景.png` 和 `9键数字页换行背景.png`。每个资源展示可复制的推荐中文名，也可下载全部 909 项的命名对照表。原标准英文名与完整中文名继续支持。
- 浅色 / 深色独立设置；复用只填充空位。支持按模块、类型、状态、前景层筛选，以及字母键 / 数字键快捷选择。
- 按最大分辨率、格式和对应大小上限校验。资源尺寸可以小于上限；点九图以含标记边框的总尺寸保守判断。
- ZIP 根目录仅有 `base/` 和 `dark/`，资源文件直接存放其下；保留原始字节、点九边框、动画和视频。没有分配的素材不会进入 ZIP。
- 这是 Theme Studio Pro 的**批量导入资源包**，不包含完整作品配置。导入后仍需在 Theme Studio Pro 内预览、自测及导出作品。

目录结构参考：[华为资源文件命名规范](https://developer.huawei.com/consumer/cn/doc/content/keyboard_designguide_filesname-0000002801098965/)。

维护源文件后运行 `node scripts/build-packager.cjs` 更新独立 HTML。规范数据由 `scripts/extract-resource-spec.py` 从用户提供的表格生成，并记录每项原始行号；不上传原始工作簿或用户素材。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动部署到 GitHub Pages。
