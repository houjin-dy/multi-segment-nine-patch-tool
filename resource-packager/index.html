怎么使用？命名、校验和导入说明

1. 上传前可按上方简名示例命名，例如“a按下.png”“删除图标.png”“通用字母背景.9.png”。字母 a～z 默认为 26 键背景，数字 0～9 默认为 9 键背景；其他按键建议加模块，如“26键空格背景.png”。默认是常规态，“按下 / 按压 / 按压态”均指按压态，“选中”指选中态。不同模块同名时会显示候选用途，不自动选中其中一个。标准英文名及原先完整中文名仍支持。

2. 同一张素材可用于多个资源：筛选模块、类型、状态，勾选目标项，批量分配。简名前景写“a前景”“a前景第2层”“a前景第4层按下”，第 1～4 层对应标准文件名中的 0～3；旧完整中文名末尾编号仍为 0～3。深浅色独立分配，复用仅填充另一模式的空位。

3. 分辨率按表格的“最大分辨率”校验，小于上限允许导出。超出尺寸、格式或大小限制的资源须先处理；本页只重命名，绝不把普通 PNG 改后缀伪装成点九，也不缩放点九边线或重编码动画。

4. ZIP 根目录直接包含 base 和 dark，所有资源位于其下，不再嵌套主题名或模块文件夹。未分配的素材不会打包，空模式保留目录；可按需要制作部分换肤项，无需凑齐全部资源。

5. 在 Theme Studio Pro 新建 / 打开“小艺输入法皮肤”作品，使用批量导入资源功能上传此 ZIP，再在工具内完成其他配置和预览自测。本包是图片 / 视频资源包，不是完整主题工程或上架成品。
